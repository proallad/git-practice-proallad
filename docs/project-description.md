# Project Description

## Project Name
Git Practice Calculator

## Purpose
This project demonstrates the practical use of Git and GitHub, including repository creation, local Git initialization, multiple commits, feature branches, merging, and pushing code to a public GitHub repository.

## Functionality
The Python program prints the student's name and the current date. It also demonstrates addition, subtraction, and multiplication using functions stored in `src/utils.py`.

## Error Handling
The calculator validates its inputs. If a non-numeric value is supplied, it raises a clear `TypeError` message.

## Technologies
- Python 3
- Git
- GitHub
